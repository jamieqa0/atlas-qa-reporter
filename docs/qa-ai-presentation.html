02 — bug report

🐛 QA 이슈 문장 빠르게 정리하기

Step / Actual Result / Expected Result — QA라면 매일 쓰는 포맷인데, AI에게 상황만 설명하면 깔끔하게 뽑아줍니다.

❌ Before — 머릿속 메모

"보상 문의하기에서 글 쓸 때 키패드 올라오면 글자 수 표시가 안 보임. 이전 버전에선 됐는데..."

✅ After — AI가 다듬은 결과 + QA 최종 검토 (중요!!)
[Step] 1. [보상] 보상 문의하기 게시판 내용 작성 [Actual Result] • 내용 작성 중 실시간 글자 수 체크 영역이 키패드 상단에 노출되지 않음 • 완료 버튼 선택 후 키패드가 내려간 이후에야 글자 수 체크 영역이 노출됨 • 4.9.10에서는 정상 노출됨 [Expected Result] • Figma 화면정의서 참조
💬

프롬프트 팁: "다음 현상을 QA 이슈 형식으로 정리해줘. Step, Actual Result, Expected Result로 나눠줘." 라고 말하면, 구어체를 구조화된 문장으로 바꿔줍니다. 환경 정보(디바이스, OS, 앱 버전)도 함께 넣어달라고 하면 더 좋아요.

03 — ocr extraction

📸 화면 캡처에서 텍스트 바로 추출

Figma 화면정의서나 앱 스크린샷을 ChatGPT에 올리면 텍스트를 추출해줍니다.
특히 기획 문서가 이미지로만 공유되거나, 긴 화면을 스크롤 캡처한 경우에 유용해요.

⚡

실제 사례: B2B DB 공급 설정 화면의 Figma 이미지에서 OCR로 텍스트를 추출 → 요구사항 분석 → 테스트 케이스 작성까지

# Figma 캡처 → ChatGPT OCR DB 공급 설정 ├─ 하단 버튼: [이전] [확인] ├─ 전국 + 수량 케이스 │ ├─ 총 계약 수량 등록 (예: 5,000건) │ └─ 미보장담보 체크 시 입력 활성화 ├─ 고객사 노출 메시지 │ └─ "암진단 미보장" 등 문구 입력 └─ 중복 등록 가능 (정책)
04 — test case

📋 요구사항 → 테스트 케이스 초안

OCR로 추출한 요구사항이나 기획서 내용을 AI에게 전달하면 TC 초안을 빠르게 뽑아줍니다.
물론 최종 검토와 보완은 QA의 몫이지만, 빈 종이에서 시작하는 것보다 훨씬 빠릅니다.

// 요구사항: "고객사 노출 메시지 — 등록할 때 고객사마다 글자수 제한 유의 필요" // → AI가 생성한 TC 초안: | TC | 검증 항목 | | TC-01 | 최대 글자수 이하 저장 | | TC-02 | 최대 글자수 초과 저장 (에러 확인) | | TC-03 | 메시지 미입력 후 저장 | // 추가로 미보장담보 중복 등록 케이스도 제안: | TC-04 | 전국+수량에서 담보 설정 후 권역별에서 동일 담보 등록 | | TC-05 | 미보장담보 미체크 시 입력 영역 비활성화 확인 |
🔑

핵심 포인트: AI가 TBD 영역은 "현재 문서만으로는 확인 불가"라고 알려줬어요. 모르는 건 모른다고 하는 것도 AI 활용의 장점입니다. 무작정 추측하는 게 아니라 "이 범위까지만 TC 가능하고, 나머지는 기획 확인 필요"라고 정리해줍니다.

표현 · 문장 다듬기

다듬은 후

"본 이슈는 클로즈 처리하였으나, Galaxy S25 Ultra에서 본문 노출 영역의 폭이 좁아 사용성 저하가 우려됩니다. 기존 이슈로 확인되며, 백로그 등록 필요 여부 검토 부탁드립니다."

06 — atlassian rovo

🔁 Rovo로 Atlassian 안에서 바로

Confluence/Jira 안에서 바로 쓸 수 있는 Atlassian Rovo도 자주 활용하고 있어요. 컨텍스트 전환 없이 작업할 수 있는 게 장점입니다.

📝 Confluence 페이지에서 바로 내용 정리 & 발표 자료 생성 ▼

지금 이 발표 자료도 Rovo에게 "제 대화 기반으로 AI 활용 사례를 정리해달라"고 요청해서 만들었습니다. Confluence 편집 화면에서 바로 요청하고, Jira 이슈와 Confluence 페이지를 자동으로 참조해서 실제 사례를 뽑아줍니다.

🔍 Jira 이슈 & Confluence 페이지 자동 참조 ▼

Rovo는 제가 최근 작업한 Jira 이슈(APTS-781, 782, 784 등)와 Confluence 페이지를 이미 알고 있어서, "내 최근 작업 기반으로 정리해줘"라고 하면 실제 데이터를 기반으로 응답합니다. 별도로 복붙할 필요가 없어요.

📊 ChatGPT vs Claude vs Rovo — 어떻게 나눠 쓰나? ▼

ChatGPT: 범용 작업에 강함 — OCR, 외부 자료 정리, 일반적인 글쓰기, 빠른 브레인스토밍
Claude: 길고 복잡한 맥락을 다룰 때 — 여러 화면/대화를 종합해서 구조를 짜야 하는 작업, 문서나 발표자료처럼 단계별로 다듬어가야 하는 작업 (이 발표 구조도 Claude와 함께 정리했어요)
Rovo: Atlassian 생태계에 특화 — Jira/Confluence 데이터 참조, 페이지 생성, 워크플로우 안에서 바로 실행

셋 다 "글을 대신 써주는 도구"가 아니라, "초안을 빠르게 만들어주는 파트너"로 쓰고 있어요.

07 — practical tips

실전에서 느낀 팁 몇 가지

🎯

역할 부여가 핵심

"너는 보험 앱 QA 담당자야" 라고 역할을 먼저 설정하면 도메인 맥락이 살아납니다. "보상"이 뭔지, "미보장담보"가 뭔지 모르면 엉뚱한 답이 나와요.

📋

포맷을 명시하기

"Step / Actual / Expected 형식으로", "테이블 형태로", "Markdown으로" — 출력 형태를 지정하면 바로 복붙 가능한 결과물이 나옵니다.

🔄

대화를 이어가기

한 번에 완벽한 결과를 기대하지 말고, "여기에 경계값 케이스 추가해줘", "이 문장 좀 더 간결하게" 식으로 대화를 이어가면 퀄리티가 올라갑니다.

⚠️

검증은 반드시 직접

AI가 만든 TC나 문장은 반드시 사람이 검토해야 합니다. AI는 "그럴듯한 거짓말"을 잘 하니까요. TBD라 명시된 건 "모르겠다"고 하는 AI가 오히려 좋은 AI입니다.
